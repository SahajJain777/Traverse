### Viewport and Sizing Rules (CRITICAL)
1. MUST include `<meta name="viewport" content="width=device-width, initial-scale=1.0">` in `<head>`.
2. The outermost container MUST use `max-width: 100%` and `box-sizing: border-box`.
3. **The ENTIRE visualisation MUST fit within the viewport with NO scrolling whatsoever.** This is the most important rule.
4. Use `height: 100vh` on the outermost container and `display: flex; flex-direction: column;` for the layout. Include `<html style="height:100%;overflow:hidden">` inline in your HTML tag, and set `<body { margin:0; padding:0; height:100%; overflow:hidden; }>`.
5. The title bar should be ~40px (`flex-shrink: 0`), control bar ~44px (`flex-shrink: 0`), variable panel ~60px (`flex-shrink: 0`). The main visual area uses `flex: 1; overflow: hidden;` to fill remaining space.
6. No element should have a fixed pixel width that exceeds the container. Keep array/data visual elements compact — prefer smaller font sizes (12px-13px) and tighter spacing so everything fits.
7. All interactive elements must have clear hover states.
